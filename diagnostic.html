GenSrpG — Diagnostic Chrome Android

Ce mode permet de reproduire le gel de Chrome et de conserver un petit journal sur ton appareil. Aucune donnée de jeu n'est supprimée et aucun journal n'est envoyé automatiquement.

1. Lancer le test

Ouvre GenSrpG avec le journal activé. Essaie uniquement une ou deux interactions. Si Chrome se ferme, rouvre cette même page de diagnostic pour consulter le journal précédent.

Le jeu est chargé depuis le même site, avec un très petit script ajouté au début. Cette méthode de diagnostic modifie légèrement le chargement, mais pas les règles ni les sauvegardes.
